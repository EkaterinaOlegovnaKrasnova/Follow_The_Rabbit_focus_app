## Возможности

### Отслеживание времени

- 8 режимов работы: Pomodoro, ReversePomodoro, Mode60_10, Mode52_17, Mode90_20, FlowMode, EatTheFrog, TimeBlocking.
- Цифровые и аналоговые часы (`digital_clock`, `MyClock`).
- Секундомер и таймер обратного отсчёта.
- Автоматическая смена фаз «работа → отдых → работа …».
- Звуковая нотификация по завершении фазы (`QApplication::beep()`).

### Управление задачами

- Создание задач «на лету»: при вводе названия в комбобокс задача сразу регистрируется в БД (`ensureTaskRegistered`).
- Списки задач с приоритетами (для EatTheFrog).
- Подзадачи внутри активной сессии (режим Pomodoro).
- Отметка выполненных задач чекбоксом.
- Синхронизация списков задач между всеми комбобоксами через сигнал `tasksChanged`.

### Аналитика

- Любимая техника пользователя.
- Средняя и максимальная длительность сессии.
- Процент завершённых сессий.
- Соотношение «работа / отдых».
- Индекс прокрастинации.
- Суммарное время за день, месяц, год.
- Выбор задачи для детального просмотра.

### Профиль и пользователи

- Аватар (из БД или заглушка `:/img/icon_question.png`).
- Имя и фамилия.
- Режим «Гость» — без записи сессий в БД.
- Формы регистрации (`new_user_form`) и выбора пользователя (`users_form`).

## Техники тайм-менеджмента

**Pomodoro** — 25 / 5 мин — Классический «помидор»: 25 минут работы, 5 минут отдыха.

**ReversePomodoro** — 5 / 25 мин — Обратный помидор: короткая работа, длинный отдых.

**Mode60_10** — 60 / 10 мин — Часовые блоки работы с коротким перерывом.

**Mode52_17** — 52 / 17 мин — Циклы, основанные на исследовании DeskTime.

**Mode90_20** — 90 / 20 мин — Ультрадианные ритмы: 90 минут работы, 20 отдыха.

**FlowMode** — Секундомер или таймер на выбор; список задач с переключением между ними.

**EatTheFrog** — Приоритизация задач (Лягушка → Элементарно); последовательный запуск по приоритету.

**TimeBlocking** — Блочное планирование дня: блоки работы + буферы между ними.

### Особенности поведения по режимам

#### Pomodoro-семейство

- На экране активной задачи отображаются: название, активность (из комбобокса), подзадача, часы.
- Кнопки «Старт / Пауза / Стоп» управляют текущей фазой.
- По завершении всех фаз задача отмечается выполненной (`activeDoneCheck->setChecked(true)`).

#### FlowMode

- Два таба: «Секундомер» и «Таймер».
- В каждом табе — свой список задач (`flowTasksList`).
- Выделение активной задачи (`activeFlowIndex`) и синхронизация времени с `digitalClock2`.
- Поддержка ввода новой задачи через комбобокс + кнопка «Добавить».

#### EatTheFrog

- Приоритеты: Лягушка (5), Сложно (4), Обычно (3), Просто (2), Элементарно (1).
- Сортировка списка по приоритету (`sortTasksByPriority`).
- Последовательный запуск задач через `startTaskSequence()`.

#### TimeBlocking

- Каждый блок: название, время работы, время буфера.
- Невидимый `blockTimer` управляет переходами между фазами.
- Фазы: работа → перерыв → следующий блок.
- При отсутствии буфера — мгновенный переход к следующему блоку.

## Жизненный цикл сессии

### Открытие

Сессия открывается при старте фазы:

```cpp
sessionStart = QDateTime::currentDateTime();
currentTaskId = <id задачи>;
currentPhase  = Phase::Work; // или Phase::Break
```

### Закрытие

Метод `finishCurrentSession(bool is_completed)`:

1. Проверяет валидность `sessionStart`, `user_id`, `currentTaskId`.
2. Формирует `Session_info` с `duration_sec = start_time.secsTo(finish_time)`.
3. Записывает в БД, если `duration_sec > 0`.
4. Сбрасывает `sessionStart`.

### Когда закрывается сессия

- Смена фазы (`nextPhase`).
- Пауза / Стоп.
- Удаление активной строки задачи.
- Скрытие окна (`hideEvent`).
- Возврат на главное окно (`on_pushButton_clicked`).

### Когда не записывается

- `user_id < 0` (гость).
- `currentTaskId <= 0`.
- `duration_sec == 0`.

## Логирование

Используется **spdlog** с макросами `SPDLOG_TRACE`, `SPDLOG_DEBUG`, `SPDLOG_INFO`, `SPDLOG_WARN`, `SPDLOG_ERROR`.

### Уровни в проекте

- **TRACE** — Создание/удаление окон, подключение ссылок, запуск фаз, заполнение комбобоксов.
- **DEBUG** — Внутренние переходы, размеры аватара, поиск задач.
- **INFO** — Запуск сессий, смена фаз, режим гостя.
- **WARN** — Отсутствие изображений, незакрытые сессии, пустые списки.
- **ERROR** — `nullptr`-указатели, невозможность запуска.

### Пример

```cpp
SPDLOG_TRACE("Комбо-бокс загружен");
SPDLOG_WARN("Информация о пользователе не загружена");
SPDLOG_ERROR("startPomodoro: передан nullptr вместо часов");
```

## Известные особенности

### Регистрация задач

- Задача регистрируется в БД сразу при вводе в комбобокс (Enter или выбор из списка).
- Метод `ensureTaskRegistered` ищет задачу по имени; если не находит — создаёт новую и эмитит `tasksChanged`.
- Это гарантирует, что любая сессия привязана к существующей задаче.

### Гость

- Комбобокс активности скрывается (`hide_combo`).
- Сессии не пишутся в БД.
- Аватар — `exit (1).jpg`.

### Незакрытые сессии

- При запуске новой фазы `startPomodoro` проверяет `sessionStart.isValid()` и предупреждает через `SPDLOG_WARN`, если предыдущая сессия не была закрыта.

### Пустые сессии

- `finishCurrentSession` пропускает запись при `duration_sec == 0` — это защищает от «мусорных» записей при быстрых переключениях.

### Удаление активной строки

- Если удаляется строка с активной задачей — таймер останавливается, сессия закрывается, происходит возврат на страницу задач.

### Синхронизация комбобоксов

- Все комбобоксы задач подписаны на сигнал `tasksChanged` и обновляют список через `refreshTaskCombo`.

### Стилизация

- Тёмная полупрозрачная тема с красными акцентами (`rgba(255,0,0,0.3)`).
- Фон окон — изображение с масштабированием.
- Все `QLabel` на странице аналитики принудительно прозрачные.
